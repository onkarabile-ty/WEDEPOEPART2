## 1. Project Overview

This project is a website created for **Press and Wash**, a laundry business. The purpose of the website is to provide customers with information about the business, its services, prices, contact details and location.

The website was developed in two phases:

- **Part 1:** Creating the website structure and content using HTML.
- **Part 2:** Designing the visual appearance and improving the user experience using CSS.


---

# Part 1 - Website Structure and Content

## 2. HTML Pages

The website contains the following pages:

### Home Page
The Home Page introduces Press and Wash and provides a short description of the laundry business. It also provides a link to the business location.

### About Us Page
The About Us page provides information about the laundry business, its experience, employees and future plans.

### Services Page
The Services page explains the laundry services offered by Press and Wash. It also provides information about prices and discounts.

### Gallery Page
The Gallery page displays images related to the laundry business and the machines used to provide the services.

### Contact Page
The Contact page provides the business telephone number, email address, operating hours and information about contacting the business.

# Part 2 - Designing the Visuals

## 5. CSS Styling

Part 2 focuses on improving the visual appearance of the website using CSS.

A separate stylesheet is used:

```text
CSS/style.css
```

Each HTML page should connect to the stylesheet using:

```html
<link rel="stylesheet" href="CSS/style.css">
```

---

## 6. Colour Scheme

The website uses a professional business colour scheme consisting mainly of:

- Blue
- White
- Black
- Light grey

Blue is used as the main business colour for navigation, headings, borders and buttons.

White is used as the main background colour to keep the website clean and easy to read.

Black is used for important text, footer sections and contrast.

Light grey and light blue backgrounds are used for content sections.

---

## 7. Typography

CSS is used to improve the readability of the website.

The design includes:

- Clear headings
- Different heading sizes
- Easy-to-read paragraph text
- Bold navigation links
- Consistent spacing
- Clear text contrast

The typography is designed to make the website suitable for a professional laundry business.

---

## 8. Navigation Design

The navigation bar has been redesigned using CSS.

Features include:

- Blue navigation background
- White navigation text
- Spacing between links
- Rounded navigation buttons
- Hover effects
- Focus effects for accessibility
- Responsive navigation on smaller screens

When a user moves over a navigation link, the link changes appearance to make it clear that it is clickable.

---

## 9. Image Design

Images are styled using CSS to improve their appearance.

The design includes:

- Rounded corners
- Borders
- Consistent sizing
- Responsive image widths
- Object fitting
- Shadows
- Hover effects where appropriate

Images are also prevented from becoming wider than the screen on smaller devices.

---

## 10. Video Design

The website video is also styled using CSS.

The video includes:

- Responsive width
- Maximum width
- Blue border
- Rounded corners
- Black background
- Automatic adjustment for smaller screens

This allows the video to remain usable on different screen sizes.

---

## 11. Responsive Design

The website is designed to work on different devices.

CSS media queries are used for:

- Desktop computers
- Tablets
- Mobile phones

On smaller screens:

- Navigation links become easier to use.
- Images resize automatically.
- Gallery images change to a single-column layout.
- Text sizes become smaller.
- Videos fit the available screen width.
- Tables adjust to smaller screens.

The purpose of the responsive design is to ensure that users can access the website comfortably on different devices.

---

## 12. User Experience

The CSS design improves the overall user experience by providing:

- Clear navigation
- Consistent colours
- Readable text
- Good spacing
- Easy-to-see buttons and links
- Responsive images
- Responsive video
- Clear content sections
- Hover effects
- Keyboard focus indicators

The design helps users find information about the business without unnecessary difficulty.

---

## 13. Accessibility

Accessibility was considered in Part 2.

The website includes visible focus indicators for links and buttons. This helps users who navigate using a keyboard.

The colour scheme also provides clear contrast between the main text and backgrounds.

Images are kept responsive so that they do not unnecessarily overflow the screen.

## 15. How to Run the Website

1. Open the project folder.
2. Make sure the HTML files, CSS folder and images folder are in the correct locations.
3. Make sure every HTML page contains the CSS link:

```html
<link rel="stylesheet" href="CSS/style.css">
```

4. Open the Home Page in a web browser.
5. Use the navigation menu to visit the other pages.
